# Supplied Main Menu Reference

The supplied reference is a 1442 × 257 px panoramic desktop-navigation crop, inspected as ordered overlapping horizontal tiles.

Tiles one and two show a dark Canopy Green header with a thin muted-green top rule. The primary labels use a large, clean sans-serif weight with relaxed horizontal spacing. The reference menu labels appear approximately **34–36px** at its original image scale, substantially larger than the previous Karossy desktop navigation. The active item uses a warm saffron tone with a narrow saffron underline.

The final tile confirms the same large label scale and generous spacing across the remaining menu items. The Karossy implementation will translate these cues proportionately rather than duplicate the reference layout: a prominent **18px** primary-menu scale at standard desktop widths, medium weight, slightly wider gaps, and the existing active-route underline and saffron emphasis. The header will preserve the responsive scale-down already needed for Karossy’s longer seven-item navigation and quote action.
